📖 របៀបឱ្យ .EXE លើ PC ផ្សេងអាច Update បាន (Distribution Guide)
១. បើ PC ផ្សេងស្ថិតក្នុងបណ្ដាញ Wi-Fi ឬ LAN ផ្ទះ/ការិយាល័យជាមួយគ្នា៖
  • នៅលើ PC ផ្សេង ពាក្យ localhost មិនអាចប្រើបានទេ (ព្រោះវារត់រកខ្លួនវា)។
  • ត្រូវប្រើ Wi-Fi / LAN Endpoint ខាងលើ (ឧទាហរណ៍៖ http://192.168.1.12:5000/api/version)។
  • អ្នកប្រើអាចចូលទៅ Settings > ៤. កំណែ និងការអាប់ដេត លើកម្មវិធី រួចបិទភ្ជាប់ Link នេះ ឬកំណត់ក្នុង app/config.py មុនពេល compile ជា .exe។
២. បើចង់ឱ្យ Update បានតាមរយៈ Internet ទូទាំងពិភពលោក (Online គ្រប់ទីកន្លែង)៖
  • វិធីងាយស្រួលបំផុត (Cloudflare Tunnel - ឥតគិតថ្លៃ): ដំឡើង cloudflared ហើយរត់បញ្ជា cloudflared tunnel --url http://localhost:5000។ អ្នកនឹងទទួលបាន HTTPS Link ឥតគិតថ្លៃ (ឧ. https://aidub.trycloudflare.com/api/version) ដែល PC គ្រប់ទីកន្លែងអាច update បាន។
  • វិធី Cloud ២៤/៧ (Render + MongoDB Atlas): ដាក់ Server នេះលើ Render.com ឬ Railway.app ហើយភ្ជាប់ទៅកាន់ Cloud MongoDB (Atlas) នោះ Server នឹងដំណើរការ ២៤ ម៉ោងដោយមិនបាច់បើក PC អ្នកចោលឡើយ។
  • វិធី GitHub Releases: បង្ហោះ .exe ទៅកាន់ GitHub Releases កម្មវិធីក៏អាច Update តាម GitHub បានដោយស្វ័យប្រវត្តិ។
